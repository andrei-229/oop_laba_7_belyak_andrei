### Описание проекта

Разработка системы симуляции боевых действий для RPG игры Balagur Fate 3. Программа моделирует боевую систему с различными типами персонажей (NPC), которые взаимодействуют в многопоточной среде.

### Основной функционал

**Система управления игровой картой:**
- Создание карты с настраиваемым размером
- Размещение NPC на карте с координатами
- Многопоточная обработка боевых действий
- Безопасное (thread-safe) управление позициями персонажей

**Типы персонажей (NPC):**
- **Dragon (Дракон)** - убивает рыцарей
- **Frog (Жаба)** - ест всех (включая других жаб)
- **Knight (Странствующий рыцарь)** - убивает драконов

**Правила боя:**
- Жаба ест всех (включая жаб)
- Рыцарь убивает драконов
- Дракон убивает рыцарей
- Проигравший NPC удаляется с карты
- Могут погибнуть оба участника боя

**Обязательные паттерны проектирования:**
- **Factory** - создание NPC
- **Visitor** - логика боевых действий
- **Observer** - оповещение о событиях убийств (консоль и файл)

## Особенности реализации

### Многопоточность
- Использование `std::thread` для параллельной обработки боевых действий
- `std::shared_mutex` для безопасного доступа к позициям NPC
- `std::mutex` для синхронизации очереди боевых действий
- Автоматическое завершение после 30 секунд симуляции

Описание:

• Реализованы три типа NPC: Dragon, Frog, Knight  
• `NPCFactory` создаёт объекты NPC по типу (паттерн Factory)  
• `BattleVisitor` проводит боевой режим между NPC (паттерн Visitor)  
• `ConsoleObserver` и `FileObserver` логируют события боя (паттерн Observer)  
• При разрушении Editor освобождаются все ресурсы  
• Координаты NPC проверяются на диапазон [0, 500]  
• Имена NPC должны быть уникальными
